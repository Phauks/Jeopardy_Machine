# Jeopardy Machine

A free, self-hosted Jeopardy-style game creation suite: visual board editor, big-screen game board, host control panel, and phone-as-buzzer play for 2-100 players who join via QR/room code - no accounts, no paywalls.

Built with SvelteKit + Svelte 5 on Cloudflare Workers, with Durable Objects powering real-time buzzing.

**Status:** research complete, no code yet. Start with [ROADMAP.md](ROADMAP.md) - it is the living index of what exists, what is next, and what is decided.
